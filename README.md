# tommys WorkSpaces 2.0

**Tomaž Dolar – Digitalni Polimat & Renesančni Ustvarjalec**

Sodobna večstranska spletna stran z animiranim ozadjem, lightbox povečavo slik, vdelanimi YouTube videi in ločenimi "svetovi" za vsako dejavnost.

## Struktura

- `index.html` – Predstavitev
- `avtomobili.html` – Svet superšportnikov + videi
- `gaming.html` – Svet iger
- `tehnologija.html` – AI, Apple, hardware
- `oblikovanje.html` – Notranje oblikovanje & studio
- `ustvarjanje.html` – Ustvarjanje vsebin
- `futurizem.html` – Metaverse, vesolje, vizije

## Kako vključiti GitHub Pages (da bo stran živa)

1. Pojdi na **Settings → Pages**
2. Pod **Source** izberi **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Shrani

Stran bo na voljo na:
